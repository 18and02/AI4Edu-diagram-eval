# AI4Edu Diagram Eval

[中文](README.md) | [English](README.en.md)

这是 2026 年 9 月 25 日图转 TikZ 工作流 v2 的单图移植版。入口是事先生成并尝试渲染的 8B 草稿。

| 草稿渲染结果 | 路线 | 处理 |
| --- | --- | --- |
| 渲染成功 | X | 根据原图校验和修正草稿 |
| 草稿存在，编译失败或渲染为空 | Y1 | 带编译或渲染反馈修复草稿 |
| PDF 页数异常或推理失败 | Y2 | 参考原图和残缺草稿重新生成 |

原图先铺白底，再以 RGB PNG 发送。题干可选，只用来确定原图已有元素的形状、位置和数量关系。每条路线最多试三次。X 重发同一请求，Y1 和 Y2 把上一轮结果与失败原因带到下一轮。第一个通过渲染质量检查的结果被采用。三次均失败时，若提供了旧版输出，则以同一套规则验证后回退。

渲染检查包括编译状态、绘制命令、坐标堆、黑底和 A–Z 字母退化图。几何正确性需要另行评估。

## 如何运行

需要 Python 3.10 以上。安装依赖后可运行离线用例。

```bash
python -m pip install -r requirements.txt
python -m unittest -v
```

实际接入时，导入 `workflow.run` 并传入以下参数。

| 参数 | 接口 |
| --- | --- |
| `image` | 原图的 `Path` |
| `draft` | `Draft`，包括 TikZ 或原始草稿、渲染状态和可选反馈。Y1 编译失败时需提供编译反馈 |
| `revise` | 接收 `Request`，其中包含 PNG 字节、按顺序送入的文本段、图像 detail 和流式设置，返回从模型响应提取的 TikZ |
| `render` | 接收候选 TikZ，返回 `Render`，包括渲染状态、PNG 路径和 PDF 提取文字。编译应在调用方提供的隔离环境内进行 |
| `stem`, `detail`, `fallback` | 可选题干、图像 detail（`auto` 或 `high`）及回退 TikZ |

`Outcome` 返回路线、每次尝试的拒绝原因、采用来源和最终 TikZ。模型调用、8B 推理、渲染和批量运行由调用方接入。渲染器可使用 PDF 提取工具提供标签文本，提取失败时传 `None`。离线用例使用合成数据和模拟适配器。
